SynergyClone — on the other PC

  1. Download the zip on both computers and extract it. Both machines need this same version.
  2. Double-click SynergyClone.exe on each one.
  3. On the PC you type on, choose Server and which edge the other screen sits on.
  4. On the other PC, choose Client. Leave the address blank and it finds the server on the network.
  5. If Windows Firewall asks, allow it on private networks.
  6. Move the mouse off that edge of the server screen. Ctrl+Alt+F12 on the server always brings control back.

The first run saves your answers beside the exe. After that, double-clicking it just starts. A tray icon shows grey while waiting, green when connected, and blue while you are controlling the other PC.

OCRCrop — on the other PC

  1. Download the zip and extract the whole folder. Keep OCRCrop.exe next to the _internal folder.
  2. Double-click OCRCrop.exe. A crop icon appears in the system tray. The first start takes a few seconds while the reader loads.
  3. Press Ctrl+Shift+Space, drag around the text, and release. Paste with Ctrl+V.
  4. Middle-click the tray icon to read an image already on the clipboard, such as a Win+Shift+S snip.

Esc cancels a selection. The tray menu has history and Start with Windows. Settings stay on that PC and are not in the download.
